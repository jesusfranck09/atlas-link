# Presentación de Atlas Link

1. Abre `http://localhost:4430` (Docker de presentación; desarrollo nativo en4300): cuenta el problema de preparar cuentas y detectar diferencias antes de entregar a la aseguradora. No prometas aprobaciones de pago.
2. En acceso hospital, pulsa **Caja** y luego inicia sesión. Los datos están identificados como demostración.
3. Recorre el tablero y las cuentas: estatus operativo y semáforo de preauditoría son conceptos distintos.
4. Descarga plantilla Excel, carga una cuenta de prueba o utiliza captura manual. Observa errores y resultado trazable.
5. Cambia a perfil **Dictaminador**: toma una cuenta, corrige un cargo con motivo, reevalúa y prepara con aceptación explícita de riesgo cuando corresponda.
6. Como **Caja**, exporta la cuenta preparada, registra el envío manual y la respuesta de aseguradora.
7. Como **Dirección**, revisa distribución, montos y tiempos disponibles; explica que todos los valores son sintéticos.
8. Como **Administrador hospitalario**, revisa usuarios, convenios y versiones.
9. Abre `/admin/login`, pulsa **Atlas Link**: muestra clientes, licencias, vigencias, capacidad y solicitudes comerciales. La empresa controla el servicio sin acceso automático al detalle de las cuentas.

Credencial demo: `AtlasDemo2026!`; el login incluye autocompletado. No utilizar estas identidades con datos reales. El correo de demostración de aseguradora solo habilita lectura de datos sintéticos.
