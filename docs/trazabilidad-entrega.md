- **O:** [alcance original](alcance-original.md), fechado 2026-09-23 21:38:14 UTC; leído completo, incluidas tablas y pendientes. Sus nombres y diseños se presentan como propuestas, pero una omisión de implementación no equivale a cancelar una capacidad solicitada.

**Sustituciones expresamente autorizadas:** microservicios reemplazan al monolito modular; Next.js/React/Tailwind reemplazan Angular/CSS puro; PostgreSQL local permite construir sin Cloud SQL. No hay instrucción explícita que suprima JSON Schema, PDF, credenciales de servicio, carga masiva, notificaciones o integración de identidad por haber elegido ese stack. La ejecución local no acredita un despliegue GCP.

## Límite de la evidencia

El cierre registra **77 pruebas Maven aprobadas**, **25 de25 pruebas nativas aprobadas**, una repetición adicional del contrato de paginación aprobada y **24 de24 vistas de la versión Docker aprobadas**. La suite nativa incluye18 análisis axe sin violaciones detectadas; la versión empaquetada también conserva cero violaciones, cero errores JavaScript/HTTP y20 cuentas de presentación intactas. Existen resultados incompletos de axe y no se afirma una auditoría integral. Los fallos anteriores se conservan como evidencia histórica y sus correcciones se repitieron. Consultar [validación](validacion.md).

Las 81 solicitudes HTTP corresponden a una ejecución histórica identificada como tal. Ninguna cifra demuestra capacidades ausentes. La revisión actual fue estática y documental; no añade una ejecución de esas suites ni da por probadas futuras correcciones.

La entrega permite demostrar flujos reales con datos sintéticos. Declarar el alcance original completo o el producto listo para operar datos hospitalarios requiere cerrar código pendiente y validar las dependencias comerciales, clínicas, legales y operativas que correspondan al primer cliente.
