# Participación del equipo

Un coordinador principal integró el repositorio, los contratos, procesos, contenedores y validación. Participaron especialistas pertinentes al producto, por áreas y en rondas de trabajo para respetar las plazas disponibles.

| Encargo | Aportación |
| --- | --- |
| Interpretación de intención | Delimitación de superficies y correcciones del stack |
| Alcance hospitalario | Preauditoría frente a HIS, roles y fronteras clínicas |
| Modelo de licencias | Venta por hospital, capacidad, vigencias y consola proveedora |
| Arquitectura backend | Servicio hospitalario, motor, revisión y exportaciones |
| Desarrollo Java | Identidad, control comercial y gateway |
| Arquitectura de datos | PostgreSQL, migraciones, aislamiento, permisos y semillas |
| Seguridad de aplicación | Sesiones, roles, acceso interno, límites y segunda revisión de nuevas capacidades |
| Arquitectura frontend | Landing, accesos, portal y consola conectados a APIs reales |
| Diseño de interfaces | Marca vectorial, contraste, tipografía, móvil y revisión con capturas |
| QA de sistema | Integración real, recorridos de navegador, accesibilidad y evidencias reproducibles |
| Análisis de requisitos | Matriz contra documento original; detección de brechas sin declararlas canceladas |
| Integridad de evaluaciones | Corrección de vigencia por ingreso, snapshots, replay, paginación y agregados |

El registro describe trabajo efectivamente delegado y recibido. No implica certificación clínica, auditoría profesional, prueba de todos los dispositivos ni revisión de agentes que no participaron.
